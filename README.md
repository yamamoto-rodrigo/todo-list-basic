# Simple To-do List

O meu primeiro projeto pessoal de desenvolvimento web, feito apenas com **HTML, CSS e JavaScript puro** (sem frameworks ou bibliotecas).

## Status atual
**Em Andamento**

Atualmente, o projeto já evoluiu muito! Já saí da manipulação básica do HTML e agora uso uma estrutura de **gerenciamento de estado** e **persistência de dados**, o que significa que:
- O JavaScript controla tudo através de um **Array de Objetos**.
- As tarefas têm **IDs únicos** para não haver confusão na hora de excluir ou concluir.
- A tela é atualizada automaticamente sempre que o Array muda.
- Tudo o que você faz fica salvo no **LocalStorage** do navegador (pode dar F5 que não some!).
- As datas são exibidas no formato brasileiro (`dd/mm/aaaa`).
- O sistema de prioridades e o feedback visual (tarefas riscadas) estão totalmente sincronizados com os dados.

Os próximos passos agora são focar 100% no **design e na experiência do usuário (UX)**, além de implementar as funcionalidades de **limpeza em massa** (botões de limpar tudo) e adicionar as validações finais (como não aceitar nomes vazios ou datas que já passaram).

## Objetivo do projeto
Construir uma To-do List funcional do zero para aprender na prática os fundamentos do front-end e aplicar boas 
práticas de código limpo, organização e Git.

## Tecnologias e Ferramentas
- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Visual moderno usando Flexbox e variáveis CSS para facilitar mudanças.
- **JavaScript puro:** Lógica avançada com manipulação de Array de objetos, LocalStorage e eventos.
