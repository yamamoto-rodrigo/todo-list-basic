# Simple To-do List

O meu primeiro projeto pessoal de desenvolvimento web, feito apenas com **HTML, CSS e JavaScript puro** (sem frameworks ou bibliotecas).

## Objetivo do projeto
Construir uma To-do List funcional do zero para aprender na prática os fundamentos do front-end e aplicar boas práticas de código limpo, organização e Git.

## Funcionalidades básicas (prioridade inicial)
- Adicionar novas tarefas
- Marcar tarefas como concluídas
- Deletar tarefas individuais
- Limpar todas as tarefas concluídas
- Contador de tarefas pendentes
- Persistência dos dados com localStorage (tarefas não somem ao recarregar)

## Funcionalidades extras planejadas
- **Níveis de prioridade** (baixa, média, alta) com cores diferentes e ordenação automática (alta no topo)
- **Editar tarefa** (clique duplo ou botão de lápis para alterar o texto)
- **Modo escuro/claro** com botão de toggle e preferência salva no localStorage

## Status atual
**Fase de planejamento**

O repositório está organizado. Em breve vou começar a estrutura HTML, depois CSS e por fim a lógica em JavaScript.

## Tecnologias que vou usar
- HTML5 (estrutura semântica)
- CSS3 puro (Flexbox, Grid, variáveis CSS, design responsivo)
- JavaScript vanilla (manipulação do DOM, eventos, localStorage)

## O que pretendo aprender com esse projeto
- Estrutura semântica e acessível em HTML
- CSS moderno, responsivo e manutenção com variáveis
- Manipulação avançada do DOM (criar, editar, ordenar elementos)
- Gerenciamento de estado simples com localStorage
- Organização profissional de repositório e commits claros
